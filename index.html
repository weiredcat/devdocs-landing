Frequently Asked Questions

Got questions? We have answers.

Can I migrate all our documents from Quip? ▼
Yes! DevDocs is markdown-native. You can export Quip folders to markdown or HTML and import them directly into DevDocs workspaces.
How does the Model Context Protocol (MCP) work? ▼
DevDocs runs a remote MCP server. When you generate an API token or authenticate via OAuth 2.1 in Claude Desktop or Cursor, the agent can call `devdocs_read_doc`, `devdocs_append_section`, and search tools automatically.
Can I run DevDocs completely offline with Ollama? ▼
Yes. DevDocs supports custom OpenAI-compatible endpoints including local Ollama (`http://localhost:11434/v1`). No prompts or document text ever leave your infrastructure.
What database is required for production? ▼
For local development, DevDocs uses zero-config SQLite. In production, it connects directly to PostgreSQL / Supabase with Row-Level Security (RLS) enforcing granular access control.
